## Contribution Scope

- **Core Standards & Governance:** The core mathematics, PER metric definitions, and Top 10 categories are stable and maintained by the project leadership.
- **Welcome Contributions:** We actively encourage Pull Requests focused on:
  1. Policy-as-Code & IaC validation rules (OPA/Rego, Semgrep, Kyverno).
  2. CI/CD automation scripts for calculating PER at build time.
  3. Mappings to external compliance frameworks (NIST, ISO, PCI-DSS).
  4. Platform-specific subtraction reference architectures.
